This code from Mathematica allows the user to reproduce all figures from https://arxiv.org/abs/2606.12712, "Predictions for and lack of maximal information transmission in the neuromuscular junction".

The code should make it easy to replace the dose-response fits used in this arXiv paper with more accurate dose-response fits, but if you have any questions, please contact Sarah Marzen at smarzen@natsci.claremont.edu.
